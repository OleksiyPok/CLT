# CLT Clock Listening Trainer

Це компактний односторінковий застосунок для вивчення часу іноземними мовами.  
Застосунок вимовляє час обраною мовою і відтворює цілий список часів поспіль. Так тренується слух на те, як час виражається в різних мовах.

<img src="img/app.png" alt="Зовнішній вигляд застосунку" width="360">

## Можливості

- Показує список випадкових годин (кожен рядок можна перекинути кнопкою з кубиком) і вимовляє будь-яку з них обраною мовою.
- Відтворює весь список по черзі (Старт, Пауза, Скидання), що тренує слух на те, як виражається час.
- Налаштуйте кількість рядків (1–15), швидкість мовлення, інтервал між часами, а також мову й голос.
- Час вимовляється природними зворотами (наприклад, «чверть на четверту») десятьма мовами.
- Працює на телефонах і комп’ютерах, 13 мовами інтерфейсу, з 10 кольоровими темами в чотирьох режимах (звичайний, вечірній, нічний, контрастний).

## Налаштування

У вікні налаштувань є швидкість та інтервал, кількість рядків, мова й голос, мова інтерфейсу, тема й режим, а також скидання до типових значень.

<img src="img/settings.png" alt="Вікно налаштувань" width="360">

## Швидкий старт

Відкрийте застосунок у браузері: https://oleksiypok.github.io/CLT/. Нічого встановлювати не потрібно, а налаштування зберігаються в браузері.
