# CLT Clock Listening Trainer

Это компактное одностраничное приложение для изучения времени на иностранных языках.  
Приложение произносит время на выбранном языке и проигрывает целый список времён подряд. Так тренируется слух на то, как время выражается в разных языках.

![Внешний вид приложения](img/app.png)

## Возможности

- Показывает список случайных времён (каждую строку можно перебросить кнопкой с кубиком) и произносит любое из них на выбранном языке.
- Воспроизводит весь список по очереди (Старт, Пауза, Сброс), что тренирует слух на то, как выражается время.
- Настройте количество строк (1–15), скорость речи, интервал между временами, а также язык и голос.
- Время произносится естественными оборотами (например, «четверть четвёртого») на десяти языках.
- Работает на телефонах и компьютерах, на 13 языках интерфейса, с 10 цветовыми темами в четырёх режимах (обычный, вечерний, ночной, контрастный).

## Настройки

В окне настроек находятся скорость и интервал, количество строк, язык и голос, язык интерфейса, тема и режим, а также сброс к значениям по умолчанию.

![Окно настроек](img/settings.png)

## Быстрый старт

Откройте приложение в браузере: https://oleksiypok.github.io/CLT/. Ничего устанавливать не нужно, а настройки сохраняются в браузере.
